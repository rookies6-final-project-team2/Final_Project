# model

주간·야간(IR) 사람 탐지 모델(YOLO 등) 학습·평가 코드.

- 이 폴더에는 **코드와 설정 파일(yaml 등)만** 올립니다.
- 데이터셋, 직접 촬영 영상(비식별 처리 전 원본 포함), 학습 결과(`runs/`), 가중치(`.pt`, `.onnx`)는 `.gitignore` 대상 → 공유 드라이브 사용
- 엔진에서 사용할 최종 가중치는 버전명과 함께 공유 드라이브에 올리고, 경로·버전을 이 문서에 기록
- 성능 평가 결과(주간/야간/IR, 오탐 유형)는 완료 보고서용으로 정리
