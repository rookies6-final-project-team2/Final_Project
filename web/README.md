# web

실시간 대시보드(WebRTC), SSE 기반 이벤트 알림, 이벤트 페이지(구간 영상 · 바운딩 박스 · VLM 판정 결과), 모바일 출동 알림 화면.

- 실시간 영상 테스트: `docker compose up mediamtx` 후 `http://localhost:8889/cam1` (WebRTC)
- 녹화 구간 재생: MediaMTX Playback API (`:9996`)
- 백엔드 API 규격: `docs/interface/api_spec.md`
- 프론트엔드 프레임워크: 추후 확정
